# IA Generativa

Este repositorio reúne tres ejercicios sobre programación e inteligencia artificial.

## Ejercicio 1: Ordenamiento de números

Contiene varias soluciones en Python para ordenar tres números ingresados por teclado y un registro de pruebas para comparar sus resultados.

- `ordenar.py`: solución propia basada en condiciones que consideran los posibles órdenes de los tres números.
- `ordenar-chat.py`: una versión del algoritmo generada con ChatGPT, usando condiciones anidadas.
- `ordenar-cloude.py`: otra versión generada con IA, también basada en comparaciones condicionales.
- `registro.md`: comparación de las tres soluciones con casos de prueba, como números desordenados, repetidos y negativos. También incluye una observación sobre las diferencias entre la solución propia y las generadas por IA.

## Ejercicio 2: Conceptos y análisis de IA

Reúne materiales para clasificar conceptos de inteligencia artificial y analizar cómo una IA toma decisiones según las instrucciones y el contexto proporcionados.

- `MapaDeConcepto.md`: resumen de IA simbólica, machine learning, deep learning e IA generativa.
- `ClasificacionDeAplicaciones.png`: captura de una actividad interactiva de clasificación de ejemplos en esas categorías; la imagen muestra la actividad completada.
- `caso_de_uso.html`: ficha del caso de uso de un asistente para responder preguntas repetidas de los coders sobre precios, con límites para evitar inventar información.
- `riwi-tres-cupos-borrador-wil.txt`: ejercicio de selección de tres estudiantes para un programa de acompañamiento. Registra una decisión individual, consultas a una IA, comparación de respuestas y una conclusión sobre cómo los objetivos y el contexto influyen en las recomendaciones.

## Ejercicio 3: Plataforma educativa gamificada

Contiene `IA-main.zip`, un archivo comprimido con un proyecto web. Dentro se incluyen una página HTML, estilos CSS y módulos JavaScript para una experiencia interactiva de formación corporativa.

El README incluido en el ZIP describe una plataforma educativa con academias de programación, inglés y habilidades blandas, retos, progreso y minijuegos. La carpeta contiene el proyecto comprimido; sus archivos todavía no están extraídos directamente en ella.
